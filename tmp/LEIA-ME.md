# tmp

Pasta para arquivos temporários: saídas de QA, capturas, prévias, rascunhos e testes avulsos. O Git ignora tudo aqui, exceto este arquivo.

- Prévias e capturas ficam em `tmp/previas/<assunto>/`, uma pasta por trabalho.
- Saídas dos scripts de QA ficam em subpastas próprias, como `tmp/forest-mvp-qa/` e `tmp/mission-qa/`.
- O conteúdo pode ser apagado a qualquer momento. Para limpar, apague tudo menos este arquivo.
- O que precisa durar e não vai para o Git, como livros, auditorias e planilhas conferidas, fica em `recursos/`, nunca aqui.
